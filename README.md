# Pedro Pinheiro

**Estudante de Desenvolvimento de Software Multiplataforma**

## Sobre mim

Sou estudante de **Desenvolvimento de Software Multiplataforma** e estou dedicando meus estudos à formação como desenvolvedor **full stack**. Tenho interesse em compreender as diferentes etapas do desenvolvimento de software — da construção de interfaces e aplicações à integração com bancos de dados.

Venho estudando linguagens como **C, JavaScript, Python e PHP**, além de tecnologias e ferramentas como **HTML, CSS, Laravel, MySQL, Git e Git Flow**. Também estou desenvolvendo meus conhecimentos em **estruturas de dados** e **orientação a objetos** por meio de atividades e projetos práticos.

Meu objetivo é evoluir continuamente e aprender a desenvolver soluções tecnológicas eficientes, funcionais e bem estruturadas. Valorizo a prática, a organização do código e a busca por formas melhores de resolver problemas.

## Competências técnicas

### Desenvolvimento web

- **HTML5 e CSS3:** estruturação e estilização de páginas web.
- **JavaScript:** fundamentos de programação e interatividade em páginas.
- **PHP:** fundamentos da linguagem para desenvolvimento web.
- **Laravel:** framework que já utilizei em atividades e projetos.

### Programação

- **C:** prática de estruturas de dados.
- **Python:** lógica de programação e resolução de exercícios.
- **Orientação a objetos:** estudo de conceitos como classes e objetos.

### Banco de dados

- **MySQL:** fundamentos de bancos de dados relacionais e consultas.

### Ferramentas e fluxo de trabalho

- **Git:** controle de versão.
- **Git Flow:** organização do trabalho com branches.
